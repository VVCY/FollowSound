01

按下去，光就起来。

七种特效，都是同一件事的不同说法：把 0 到 1 的音量，变成 0 到 180 像素的光。

光带

下面这块和 App 里跑的是同一份渲染代码（Canvas 版），桌面上是更细腻的图层版本。 点特效名字即时切换；接上麦克风，它会跟着你说话亮。

02

一个小工具，只做一件事。

不做录音笔，不做会议记录，不做语音识别。它只管把音量画出来。

隐私

只读音量，
不知道你说了什么

音频在内存里算一次均方根就丢掉，不落盘、不联网、不识别内容。麦克风权限只为读音量存在， 关掉 App 就释放设备。

高度

无级调节，
拖到哪就是哪

80–400 pt 之间任意拖。拖动时画面直接顶到满高，不用猜“调到 220 会有多高”。

不打扰

贴着屏幕底边，
不挡点击

覆盖层永远不接收鼠标事件。它在所有空间都在，全屏演示时也在，但你可以直接点穿它。

静音超过半秒自动降到 15fps，一有声音立刻回到 60fps。空闲时 CPU 占用通常低于 1%。

07

几个问题

它真的不录音吗？

不录。音频缓冲区只用来算一个均方根（音量），算完就丢。代码是开源的，可以自己看。

为什么 macOS 版打开时提示“无法验证开发者”？

没有走 Apple 公证（要 99 美元一年）。右键点图标 → 打开，之后就不会再问。

会挡到我点东西吗？

不会。覆盖层设置了点击穿透，鼠标事件直接落到下面的窗口。

以后会收费吗？

当前没有付费计划。如果哪天要做更重的东西（比如多轨、录制），会另开一个产品，不锁现有功能。
