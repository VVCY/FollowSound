### 随响 FollowSound

把说话的音量，变成屏幕底边的一条光带。不录音、不上传、不需要账号。

**本次更新**

- 首个公开版本：7 种特效（光带 / 色差光带 / 横向镜头光斑 / 像素拉丝 / 均衡器 / 波纹 / 星雨）
- 24 套配色，悬浮即预览
- 高度 80–400 pt 无级调节，拖动时画面实时满高预览
- 由 HappyVoice 更名为「随响 FollowSound」，图标换成白底透明的声波
- 三端一致：macOS 原生 / Windows / Android
- 应用内检查更新，走本页的 Release

**安装**

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| macOS 14+ | `FollowSound-macOS-x.y.z.zip` 或 `.dmg` | 未公证，首次打开请右键 → 打开 |
| Windows 10/11 | `FollowSound-Windows-x.y.z-Setup.exe` | 未签名，SmartScreen 选「仍要运行」 |
| Android 8+ | `FollowSound-Android-x.y.z.apk` | 需允许「显示在其他应用上层」 |

`SHA256SUMS.txt` 是上面所有包的校验值。

`https://github.com/VVCY/FollowSound/releases/latest/download/FollowSound-macOS.zip` 等，详见 `docs/RELEASE.md`。
